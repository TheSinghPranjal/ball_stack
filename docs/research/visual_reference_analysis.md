# Visual Reference Analysis

## Primary reference (from materials/CSS in bundle)

- Low-poly flat-shaded tower (`flatShading`, roughness ~0.6), vertex colours, alternating two-tone safe slots.
- Danger slots: saturated red with emissive glow and a darker red lip on top.
- Deep dusk-gradient skies per stage with matching fog; pillar in a contrasting cool hue with lighter bands.
- Golden base platform at the bottom of the tower.
- Display font for headings (geometric sans), friendly sans for body.

## Our original direction ("candy-glass arcade")

We keep the genre's readability rules but use our own palettes, shapes and branding:

- **Platforms**: thick rounded-edge discs with bevel strip; two-tone alternating slots; slight gloss highlight.
- **Danger**: charcoal-black core with hot magenta-red rim (reads as "hazard" for colour-blind users thanks
  to the dark value contrast, not only hue).
- **Breakable**: lighter tint with dark crack stripes. **Bonus**: gold with emissive glow.
- **Pillar**: frosted white-tinted column with coloured rings.
- **Backgrounds**: vertical gradient + soft radial bloom + drifting bokeh particles.
- **Ball**: glossy sphere with banded pattern so rotation is visible; skins change material.
- **Themes** (original palettes): Sunset Soda, Mint Lagoon, Berry Night, Citrus Sky, Coral Reef, Aurora.
- **Typography**: system rounded heavy weight (no bundled third-party font) with outline/shadow styling.
