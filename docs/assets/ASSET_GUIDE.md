# Asset Library

All assets are original and generated by code in this repository:

| Kind | Generator | Output |
|---|---|---|
| Logo, app icon (+ Android mipmaps / iOS AppIcon set), coin, star, shield, gift, victory/failure art | `tools/gen_assets.py` | `assets/images/**`, `android/.../mipmap-*`, `ios/.../AppIcon.appiconset` |
| 20 SFX + 8-bar music loop (PCM16 mono 32 kHz, synthesised) | `tools/gen_assets.py` | `assets/audio/**` |
| Ball, platforms, hazards, pillar, base, debris, decals | runtime procedural meshes | `lib/core/render3d/mesh_factory.dart`, `platform_controller.dart` |
| 8 ball skins (material + pattern + trail) | data | `lib/features/shop/data/skin_catalog.dart` |
| 6 environment themes | data | `lib/app/theme/colors.dart` |

`assets/asset_manifest.json` lists every asset with path, format, dimensions, usage and loading priority.
Regenerate: `python3 tools/gen_assets.py` (requires Pillow + NumPy).

## Budgets

- Ball: 10–18 stacks × 18–34 slices (≤ 1,150 tris) by quality.
- One floor: ≤ 1,200 tris (asserted by `test/unit/renderer_test.dart`), ~400–700 typical.
- Visible scene: 9–13 floors + debris pool (72 shards) + 360 particles.
- Textures: none at runtime in 3D (vertex colours) → zero texture memory for the scene.
- Audio: ~1.5 MB total, SFX preloaded into `AudioPool`s, music streamed by a looping player.
